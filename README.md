# chono-fallout

Isometric pixel art RPG inspired by Chrono Trigger and Fallout. Built with Godot 4.

## Getting Started

1. Open Godot 4 (latest stable) and select this folder as the project.
2. The main scene is `scenes/Main.tscn`.
3. Press Play to run.

## Project Structure

- `project.godot` – Project settings
- `scenes/` – Scenes (entry: `Main.tscn`)
- `scripts/` – GDScript scripts
